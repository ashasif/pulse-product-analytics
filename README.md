# Pulse — Product Analytics & Subscription Intelligence Platform

An end-to-end portfolio project simulating the product analytics environment of a fictional consumer AI productivity application.

> **Important:** Pulse and all datasets used in this repository are synthetic and created solely for portfolio and learning purposes.

## Product

Pulse is a fictional AI productivity application operating on a:

**Freemium → Free Trial → Monthly/Annual Premium subscription model**

Core features include:

- AI Assistant
- Smart Tasks
- Document Summariser
- Focus Sessions
- AI Notes

## Project Goal

The project is designed to demonstrate practical skills across:

- product analytics
- analytics engineering
- data quality
- PostgreSQL and SQL
- experimentation
- subscription and revenue analytics
- retention and churn analysis
- customer lifetime value
- statistical and machine-learning analysis
- forecasting
- internal analytics application development

## Planned Architecture

Synthetic configuration  
→ Python synthetic-data engine  
→ Raw files  
→ Python ingestion and validation  
→ PostgreSQL raw layer  
→ PostgreSQL staging layer  
→ SQL transformations  
→ PostgreSQL analytics layer  
→ Statistical / ML analysis  
→ Streamlit analytics application  
→ Testing and reconciliation
